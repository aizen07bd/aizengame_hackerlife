# Hacker Life: Trace

해커가 되고 싶었던 한 대학생이 작은 사건들을 따라가며 진짜 보안 분석가로 성장하는 모바일 추리 스토리 게임입니다.

플레이어는 미연시 스타일의 대화와 컷씬을 따라가며 의뢰인의 말을 듣고, 로그와 기록을 살펴보고, 의미 있는 증거를 골라 결론을 세웁니다. 단순히 정답을 맞히는 게임이 아니라, 왜 그 기록이 근거가 되는지, 어떤 정보는 함정인지, 어디까지 말할 수 있고 어디부터는 단정하면 안 되는지를 직접 판단하게 됩니다.

## 게임 특징

- 실사풍 캐릭터와 4컷 만화식 컷씬으로 진행되는 보안 드라마
- 피싱, 세션 복원, 브라우저 흔적, 웹 서버 로그, 보안장비 이벤트, 포렌식, 악성코드 분석까지 이어지는 단계형 구성
- 실제 시스템을 공격하지 않고, 사건 상황에 맞춘 안전한 조사 화면으로 학습
- 증거 선택, 반론, 결과 판정으로 이어지는 보안 분석가식 사고 훈련
- 모바일에서 바로 플레이할 수 있는 웹 기반 구성

## 한 줄 소개

흔적을 보고, 단서를 고르고, 성급한 결론을 버려라.  
`Hacker Life: Trace`는 해킹 기술보다 중요한 분석의 태도를 배우는 보안 추리 게임입니다.
